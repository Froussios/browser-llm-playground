The Prompt API is not exposed on this page.
  1. Use a recent desktop Chrome (or Canary/Dev).
  2. Open chrome://flags/#prompt-api-for-gemini-nano and set it to Enabled.
  3. Open chrome://flags/#optimization-guide-on-device-model and set it to Enabled BypassPerfRequirement.
  4. Relaunch Chrome, reload this page. If availability says downloadable, sending the first prompt starts the model download. Progress can also be watched at chrome://components (Optimization Guide On Device Model).
