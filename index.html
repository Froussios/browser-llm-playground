The Prompt API is not exposed on this page.
  1. Use desktop Google Chrome 148 or newer on Windows, macOS, Linux or ChromeOS. Other Chromium browsers may not include the API. Update Chrome at chrome://settings/help.
  2. On Chrome 148 or newer the API is normally on without flags. If it is still missing, open chrome://flags, search for Prompt API and on device, enable any matching entries that exist, and relaunch. Flag names vary by version, and some builds have none.
  3. Check the model status, and why it is unavailable, at chrome://on-device-internals. If that page is blocked, enable internal debug pages at chrome://chrome-urls first.
